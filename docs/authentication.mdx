# Authentication

In order to get started building with the InfoSum APIs you first need to generate an API key via the Platform UI.

<Admonition type="note">
You must set the value for `authorization` header to your API key for all API requests to `/api/` paths.
</Admonition>

Head to the [API keys](https://accounts.infosum.com/access/api-keys) page in your InfoSum Account. It appears in the sidebar navigation under **Access &rarr; API keys**.

If you have previously generated keys you will see them listed here. If not you will see the following screen:

<img src={NoAPIKeysImageURL}/><p/>
Select **NEW API KEY** and you will be given a date selector for the expiry date for the new API key:

<img src={SetExpiryImageURL} className="center_half_image" /><p/>
On submitting the expiry time you will be given your API Key:

<img src={GrantedAPIKeysImageURL} className="center_half_image"/><p/>
Please store your API Key safely for later use. After you close this pop-up, you will not be able to view the key again.
